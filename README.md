# Facilities Hub

## Project Overview

Facilities Hub is a Microsoft Power Platform-based application designed to streamline employee facility management, facility access requests, and issue reporting.

The solution uses Microsoft Power Apps, Microsoft Dataverse, and Power Automate to provide a centralized platform for managing facility-related operations and automating request approval workflows.

## Technologies Used

- Microsoft Power Apps (Canvas App)
- Microsoft Dataverse
- Microsoft Power Automate
- Microsoft Excel Online (Business)
- Office 365 Outlook
- Standard Approvals
